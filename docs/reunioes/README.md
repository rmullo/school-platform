## Como registrar

Usar nomes no formato `AAAA-MM-DD-assunto.md` e o [modelo](TEMPLATE.md). Registrar apenas participantes, decisões e encaminhamentos confirmados pela fonte. Uma conversa em chat deve ser identificada como conversa, sem inventar uma reunião.

Decisões técnicas detalhadas terão vínculo com [decisions/](../decisions/README.md).

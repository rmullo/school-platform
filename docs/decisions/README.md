## Situações do registro

- **Proposta:** conteúdo apresentado para discussão.
- **Em aberto:** pontos ainda em discussão.
- **Aceita:** decisão com aprovação identificável.
- **Substituída:** decisão anterior vinculada ao registro que a substituiu.

## Como registrar

Preencher contexto, decisão, consequências, alternativas e fonte usando o modelo. Manter a situação de cada ADR neste índice. Não atribuir argumentos ou aprovações a pessoas sem uma fonte que os confirme.

Se uma decisão mudar, preservar o registro anterior e apontar para a nova decisão.

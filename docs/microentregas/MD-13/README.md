# MD-13 — Livros, materiais e uniformes

**Situação:** implementada e em validação; [TASK-0016](../../tasks/TASK-0016-md13-materiais-e-uniformes.md).

Foram criados kits por ano/série, itens com origem externa/escolar/cortesia, tipo de livro/material/uniforme, opcionalidade e pedidos com estados independentes de pagamento e entrega. A API e a interface não usam pedido de material como requisito para matrícula ou conclusão.

Fornecedor, gateway, estoque real e fiscal não fazem parte desta etapa. Os testes manuais devem usar itens fictícios e confirmar a independência dos fluxos.

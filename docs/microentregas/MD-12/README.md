# MD-12 — Rematrícula e transferência

**Situação:** implementada e em validação; [TASK-0015](../../tasks/TASK-0015-md12-rematricula-e-transferencia.md).

Foi criada a trilha auditável de transições de aluno para rematrícula ou transferência, com destino, ciência quando informada, liberação documental e revisão financeira descritiva. A chave de operação impede duplicidade e nenhuma dívida de irmão ou de outra escola é consultada como bloqueio.

A criação efetiva de uma nova matrícula escolar continua dependente da escolha de ano/turma/plano no fluxo de matrícula existente; esta entrega registra a decisão administrativa sem inventar uma vaga. Não há integração com outra escola nem dados reais.
